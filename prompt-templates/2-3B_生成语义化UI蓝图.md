# Prompt 2.3B：生成语义化 UI 蓝图

文本组件树比模糊草图更容易被实现阶段遵守。蓝图必须绑定 Schema 字段，并覆盖空态/加载/错误，而不是只画成功屏。

页面数量、是否使用路由、是否有导航，以 PRD 为准，不要把「单屏、禁止 NavBar」写成硬性架构。

---

```text
<Role>
你是前端架构师，输出供实现使用的 UI 蓝图（纯文本，不要图片链接）。
</Role>

<Context>
产品按 PRD 的信息架构来，不默认单页、也不默认后台套件。
组件树中出现的数据字段必须来自 @docs/schema.md。
</Context>

<Input>
团队选定的风格：【粘贴 2.3A 中选中的提案要点】
结合 @docs/schema.md 的字段与 Mock。
必要时回看 @docs/PRD.md 的页面与状态要求。
</Input>

<Task>
输出 `docs/UI_BLUEPRINT.md`，作为前端实现的视觉与结构说明。
</Task>

<Output>
文件：`docs/UI_BLUEPRINT.md`

# UI 蓝图：[风格名称]

## 1. 信息架构
- 页面或路由列表（若仅一页，说明区域内如何分区）
- 全局导航/页头/页脚是否存在、进哪些页面
- 权限相关入口（登录、当前用户）若 PRD 需要则写出

## 2. 设计规范
- 主色 / 中性色 / 语义色（成功、警告、错误），可用 Tailwind token 描述
- 背景、文字对比、字号层级
- 组件形态（圆角、边框、密度、是否使用已有组件库）

## 3. 状态
每个主页面至少说明：
- 空态 / 首次进入
- 加载
- 成功（绑定 Schema 字段）
- 错误（校验、401、服务端失败）
不要用「断网时展示假数据」充当错误处理。

## 4. 组件树
用缩进列出 DOM/组件层级。在叶子上标注绑定的 Response/Request 字段名。
示例（按产品替换，不要照抄「单屏工作区」）：

- `<AppShell>`
  - `<TopNav>`（产品名、主导航、用户菜单）
  - `<Page: Detail>`
    - `<Summary>` ← 绑定对应资源的主键与标题字段
    - `<RecordList>` ← 绑定列表数组字段
    - `<StatusBar>` ← 绑定状态 / 时间字段
    - `<ErrorBanner>` ← 绑定 `error.code` / `error.message`

## 5. 交互要点
主路径点击/提交后请求哪个接口、成功/失败时跳转或就地更新哪一块。
</Output>
```

---

### 人类核对

1. **IA 与 PRD**：该有的页面和导航在树上；不该有的营销落地页结构删掉。
2. **字段对齐**：分屏对照 `schema.md`，蓝图不得发明后端没有的字段。
3. **状态齐全**：加载与错误有明确组件，而不是空白等接口。

# 迭代沟通工具箱（双轨）

---

## 轨道一：硬性否决

### 错误 1：结构与 PRD 冲突

```text
<Reject>
组件树的页面/导航与 PRD 不一致：缺少必要入口，或增加了 PRD 没有的站点框架。
</Reject>

<Anchor>
先按 PRD 列出页面，再填组件。路由和 Nav 按产品需要保留或删除，不要执行「禁止导航」这类与需求无关的禁令。
</Anchor>

<Action>
重写【1. 信息架构】和【4. 组件树】。
</Action>
```

### 错误 2：数据绑定对不上 Schema

```text
<Reject>
组件绑定了 Schema 中不存在的字段（例如 【字段名】）。按这份蓝图实现会在运行时取到 undefined。
</Reject>

<Anchor>
只绑定 schema.md 中的字段。缺展示数据应先改 Schema（并经人确认），再改蓝图，禁止前端发明字段。
</Anchor>

<Action>
逐字段核对 Mock，删除或改写幽灵绑定，重出【4. 组件树】。
</Action>
```

---

## 轨道二：柔性咨询

### 疑虑：重依赖交互是否值得

**触发**：蓝图出现必须新装的动画/3D/拖拽框架，而 PRD 未要求该交互。

```text
<Doubt>
组件树用了【填写：某动画库 / 3D / 拖拽体系】。这是否为 PRD 主路径所必需？
</Doubt>

<Explore>
先不改蓝图。给出：
1. 原方案的必要性
2. 用现有栈（React 状态 + CSS）能替代到哪一步
3. 若保留：建议的库与理由
</Explore>

<Action>
只给选项，等我决定后再改蓝图。
</Action>
```

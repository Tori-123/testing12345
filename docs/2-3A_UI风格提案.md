# 2.3A UI 风格提案

约束：单屏 SPA。输入 / 加载 / 结果只靠同一画布上的显示与隐藏。禁止导航栏、侧边栏、路由、3D、粒子、动画库。视觉必须能用原生 Tailwind 一次写对。

数据绑定以 `docs/schema.md` Mock 为准：棋盘 `fen` + `g2→g4` 高亮，`g4` vs `Nf3`，评估 `+1.6 → -2.8`，三句 `mistake` / `plan` / `cue`。

---

### 提案 1：深夜课桌 (Night Desk)

- **视觉基调 (Vibe)**: 接近关灯后的书桌。底色 `zinc-950`，主表面 `zinc-900` 卡片，细 `zinc-800` 描边。文字 `zinc-100`，次要信息 `zinc-500`。唯一强调色是评估掉分用的暗红 `rose-500`（数字和 g4 高亮格），引擎应着 `Nf3` 用冷青 `teal-400`。标题用无衬线（Tailwind `font-sans`），三句讲解用稍大行距的 `font-serif`，像有人在纸页空白处写了批注。无发光、无渐变网格、无玻璃拟态叠层。

- **布局逻辑 (Layout)**: 单列，最大宽度约 720px 居中。上方只留产品名 PlyHan 一行小字，不是导航。初始态：大文本框占上半（贴 PGN）+ 并排两个按钮「载入示例」「复盘这一手」。点击后文本框仍在，按钮禁用，其下出现一行「正在找败着」和细进度条（CSS 即可）。结果态：文本框收成可折叠的短条，主视觉换成棋盘（左或上）与右侧/下方三张卡片，标题锁死为「错在哪 / 当时该怎样 / 下次先看什么」，正文绑 `mistake` `plan` `cue`。评估掉分 `4.4` 做成棋盘上方一条短红线旁的数字，不单独做仪表盘页。错误时只在按钮下替换一行 `error_message`。

- **为什么适合本产品**: 用户是 23:24 还对着红条发呆的高二棋手，这个界面像关灯后只留一盏台灯，不会再刺激他开一盘。

---

### 提案 2：赛后记录表 (Scoresheet)

- **视觉基调 (Vibe)**: 纸质记分卡。底色暖米 `stone-100`，卡片 `white`，边框 `stone-300`。标题衬线、正文无衬线。棋盘用经典绿白格（`green-700` / `stone-50`），不要霓虹。败着格子用半透明 `red-400` 盖一层，引擎着法格子用 `amber-200`。数字评估用等宽 `font-mono`，像打印出来的 `+1.6 / -2.8`。整体克制、俱乐部海报感，不是 App 感。

- **布局逻辑 (Layout)**: 仍是单屏。上缘一条细横线 + 手写感小标题「第 26 手 · 白」。初始：记分卡上半是空白「粘贴棋谱」横格文本框（等高线用 Tailwind 边框模拟）。结果：左栏棋盘固定，右栏三块盖章式条目——Mistake / Plan / Cue 用中文标签，避免英文导航幻觉。加载时棋盘位置先出现空格棋盘骨架（灰格），避免整页空白。`degraded: true` 时在记分卡右上角盖一枚小印章「示例局面」，不是弹窗。

- **为什么适合本产品**: 复盘的本质是「这一手记在谱上」，纸质记分卡让评委 90 秒内看懂：我们不是又一个人机网站，是在圈败着。

---

### 提案 3：红条特写 (Redbar Crop)

- **视觉基调 (Vibe)**: 杂志裁切。近黑底 `neutral-950`，但中央有一块高对比白卡片专门放三句人话，像从 Lichess 评估图上剪下来的局部。强调色只用一种：评估条红 `red-600`。棋盘深色主题（深灰格），高亮 `g2-g4` 用实心红框，不要箭头动画。字体全无衬线、字重拉开：`user_san` 极大（`g4`），`engine_san` 较小（`Nf3`），形成「你走的 / 该走的」并置。禁止赛博网格、扫描线、故障艺术——那些会诱使 Agent 加自定义 CSS 动画。

- **布局逻辑 (Layout)**: 垂直三分，始终同一屏。顶：输入条（PGN 压缩为矮文本框，示例按钮做成文字链而不是导航）。中：加载时只显示一根从左向右变短的红条（纯 CSS `width` 过渡一次即可），文案「正在找掉分最大的一手」。底/结果：左棋盘右白卡片；白卡片内按 Mock 三段原样排版，字数已很长，卡片要可 internally scroll，禁止跳页。`eval_before` 与 `eval_after` 做成棋盘顶上一行对照：`+1.6` 划掉，`-2.8` 红色。没有仪表、没有多步时间轴。

- **为什么适合本产品**: 痛点就是评估条上的那根红线；这个风格把产品缩成「红条特写 + 人话」，评委视线会先落到 `g4` 再落到三句话。

---

## 怎么选

| 提案 | 给 Agent 的难度 | 路演记忆点 |
| --- | --- | --- |
| 1 深夜课桌 | 最低，标准暗色卡片 | 情绪贴近 Persona |
| 2 赛后记录表 | 低，浅色 + 绿棋盘 | 最不像「又一个 AI 聊天框」 |
| 3 红条特写 | 低，但大字号排版要防溢出 | 最贴「对着红条发呆」这句 slogan |

三案都不要粒子背景、不要对局时钟、不要第二页。选一个后进入 2.3B 蓝图，组件树将直接绑 Mock 字段。
